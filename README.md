### Featured work

#### 🏠 [Llavik](https://llavik.com) — Real-estate CRM (SaaS)
Lead collaborator · ~300 commits · private repo

A CRM where each agency manages its listings, leads, schedule, contracts and rent
collection, with its own public website and listings published to property portals.

- Multi-tenant architecture on **Next.js 16** (App Router, server actions) + **PostgreSQL / Prisma**
- Lead–property matching, rent collection, transactional email and an **AI assistant**
- **WhatsApp Business** integration (Meta API) with media attachments and voice notes
- **600+ automated tests** and CI/CD: every merge to `master` deploys itself to a Linux VPS

`Next.js` `TypeScript` `PostgreSQL` `Prisma` `Tailwind` `GitHub Actions` `nginx`

#### ⛅ [App Clima](https://github.com/pedrogattii/appClima) — Weather app
Weather search by city using the OpenWeatherMap API, with dynamic icons per condition.

`JavaScript` `HTML` `CSS` `REST API`
